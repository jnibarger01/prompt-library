## Import notes

The README's 104 `text` code blocks were imported as individual library entries, preserving their titles and prompt bodies. The master `system_prompt.md` was also added as one long-form system-prompt entry; its 104 embedded templates are the same templates already imported individually.

The two shell snippets for installing agent skills, the README's explanatory prose, and the upstream `Skills/` package files were not added as prompt entries because they are setup instructions, documentation, or agent-skill packaging rather than additional standalone prompt templates.

All entries were mapped into the prompt-library's existing 14 categories. No new categories were introduced. Imported entries carry the tags `rea`, `rea-prompts`, `reverse-engineering`, `static-analysis`, and `evidence-driven`, plus section-specific tags.

Before import, the 105 candidates were checked against the existing 2,207 prompts for exact IDs, titles, bodies, and token-set Jaccard similarity using the library tokenizer. No exact or near-duplicates met the 0.45 threshold.

The original prompt wording was retained. The upstream MIT copyright and permission notice is reproduced in the accompanying license file.
